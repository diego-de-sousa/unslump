# Custom PWA Icons & Branding

Replace placeholder icons with professionally designed custom icons featuring the unslump! brand identity. Include all required sizes for iOS, Android, and desktop PWA installation.

## Rationale
Professional icons are essential for user trust and app store discovery. Competitors like Stretchly face signing issues on macOS - our PWA approach avoids this entirely with proper branding.

## User Stories
- As a user, I want the app icon to look professional so that I feel confident installing it on my device
- As a user sharing the app, I want the social preview to look polished so that my colleagues take it seriously

## Acceptance Criteria
- [ ] Custom icon-192.png and icon-512.png designed with unslump! brand
- [ ] Apple-touch-icon.png properly sized for iOS
- [ ] Open Graph image (og-image.png) designed for social sharing
- [ ] Favicon updated to match brand identity
- [ ] All icons pass PWA Lighthouse audit
